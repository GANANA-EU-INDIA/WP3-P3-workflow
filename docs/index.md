# pMHC-TCR MD and Free Energy Workflow Documentation


Documentation to deploy and use automated workflows for conformational simulations and free energy computations of pMHC-TCR proteins complexes using GROMACS and PyCOMPSs.

**Start here:** [Quickstart Guide](quickstart.md) · **Source code:** [GitHub Repository](https://github.com/GANANA-EU-INDIA/WP3-P3-workflow)


This is part of the GANANA [Life Science pillar (WP3)](https://ganana.eu/the-project/#life-sciences) - Project 3 "Framework for AI-driven Immunogenic Peptide Prediction".
